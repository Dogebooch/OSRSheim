## Blocker (found 2026-09-20 morning, RESOLVED same morning): `raiseskill` was dead

`raiseskill <skill> <n>` echoed and did nothing. Root cause from
`LogOutput.log`: `MissingMethodException: Method not found: void
Character.Message(MessageHud/MessageType,string,int,UnityEngine.Sprite)` with
`Skills.DMD<Skills::CheatRaiseSkill>` as the top frame. A Harmony patch in
**Blacksmithing 1.3.5** called the pre-1.0 four-argument `Character.Message`;
Valheim 1.0 takes five. Confirmed by scanning every plugin DLL's MemberRefs:
only `Blacksmithing.dll` referenced the 4-arg form.

**Fix applied:** Blacksmithing 1.3.6 + Ranching 1.1.9 (both Hexium, 1.0-built;
Thunderstore was stale) installed through Gale. The 08:00 launch logs zero
exceptions (the 07:56 `Player-prev.log` had 32). `raiseskill` itself has NOT
been re-run since; do that before tests 9, 11, 12 (STATE item 26).

Ungated fallbacks if it still fails: `SledgeStagbreaker`, `BowFineWood`,
`ArrowFlint` equip at skill 0. `SledgeIron` correctly REFUSED at Clubs 0
