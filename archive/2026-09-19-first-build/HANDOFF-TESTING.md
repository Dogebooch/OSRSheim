EpicLoot tables still roll zero magic items. 0 errors as of 2026-09-20.

### Superior zero-star fallback (test 6)
If superiors spawn but at zero stars, Spawn That's `UseDefaultLevels` is being
overridden by CLLC "Maximum stars = None". Fallback (stars stay off globally):
drop the level trick and switch the superior loot conditions from
`ConditionMinLevel = 3` to a `ConditionLocation` / `ConditionHasItem`-style
condition, OR raise CLLC `Maximum stars` to `Two` with all star chances 0.

## 3. Server standup (Phase 8)

- **Launch flags verified** against Iron Gate's guide; template is
  `scripts\server-start-template.bat`. Syntax `-modifier <name> <value>`,
  `-setkey <key>`; values in the template header. Recommended: `-modifier
  deathpenalty casual` (keep gear, drop inventory, 1% vanilla-skill loss),
  `-setkey playerevents` (raids follow each player). `portals` is still the
  open design decision; `raids more` adds random-event chaos.
- **Deploy payload** = the Gale profile root: `winhttp.dll`,
  `doorstop_config.ini` (target already relative), `doorstop_libs\`,
  `BepInEx\`. Linux hosts use the profile's `start_server_bepinex.sh`.
- Doug's SteamID64 goes in `adminlist.txt` before first launch (already in KG
  `OverrideDebug`).
- Teleporter and Territory configs are coordinate-blind templates: fill them
  from the in-game `pos` command once Gielheim exists.
- Stop the server through its own shutdown path, never a hard kill: Valheim
  1.0 discards a world whose main files are newer than its `.ok.stmp`.
